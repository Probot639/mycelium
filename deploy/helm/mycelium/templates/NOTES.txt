2. Create the campaign and upload a harness. Run this once, from a machine that
   has the harness binary and the mycelium CLI. Reach the coordinator with a
   port-forward:

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "mycelium.fullname" . }}-coordinator {{ .Values.coordinator.service.port }}:{{ .Values.coordinator.service.port }}

   mycelium inoculate --coordinator localhost:{{ .Values.coordinator.service.port }} \
     --campaign {{ .Values.campaign.name }} \
     --harness ./your_harness \
     --fuzzer aflpp \
     -- afl-fuzz -i {corpus} -o {output} -M main -F {inject} -- {harness}

2. The inoculate Job ran as a post-install hook and created campaign
